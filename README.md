# Tic Tac Toe Game 🎮

A classic, interactive Tic Tac Toe web game built using HTML, CSS, and JavaScript. Challenge your friends to a match with smooth 
glowing visuals and custom win/draw pop-up animations!

## ✨ Features
* **Two-Player Mode:** Take turns playing as **X** and **O**.
* **Modern UI & Animations:** Glowing neon styling, smooth CSS transitions, hover effects, and a custom animated pop-up modal for wins and draws.
* **Responsive Grid:** Clean layout built using CSS Grid and Flexbox.

## 🛠️ Built With
* **HTML5** - Structure and layout
* **CSS3** - Styling, variables, gradients, and keyframe animations
* **JavaScript (ES6)** - Game logic, DOM manipulation, and event handling

## 🚀 How to Play
1. Clone or download this repository.
2. Open `index.html` in any modern web browser.
3. Player X goes first, followed by Player O. Connect three of your marks in a row (horizontally, vertically, or diagonally) to win!
